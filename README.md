# Nemo – AI Workplace Productivity Assistant

**Work Smarter. Let Nemo Handle the Rest.**

Nemo is an AI-powered workplace productivity platform designed to automate common business tasks through a single integrated dashboard. The application combines multiple AI tools into one modern workspace, helping professionals improve productivity, reduce repetitive work, and make better decisions.

---

# Project Overview

Professionals spend a significant amount of time writing emails, planning schedules, summarising meetings, conducting research, and answering repetitive workplace questions.

Nemo addresses these challenges by bringing multiple AI-powered workplace tools together into one application with a clean, professional, and responsive interface.

# Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/Nemo.git
```

Navigate into the project:

```bash
cd Nemo
```

Create a `.env` file in the project root:

```env
OPENAI_API_KEY=your_openai_api_key
```

Ensure that `.env` is listed in `.gitignore` so your API key remains private.

Run the project using your preferred local development server.

---

# Environment Variables

Create a `.env` file:

# Responsible AI

Nemo is designed to support responsible and ethical AI usage.

Users should always:

- Review AI-generated content before use.
- Verify important information.
- Confirm research findings independently.
- Avoid relying solely on AI for legal, financial, medical, or business-critical decisions.
